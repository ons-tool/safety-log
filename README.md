# 안전교육일지 (GitHub Pages 정적 버전)

서버·DB 없이 동작합니다. 입력 내용은 어떤 서버로도 전송되지 않습니다.

## 사용 순서
상단 배너(탭)에서 🦺 안전교육일지 / 🔒 보안교육일지를 고릅니다. 두 양식의 입력 내용·명단·서명 링크는 따로 저장됩니다.

1. 교육자 기기에서 `index.html`을 열고 일지 작성 (참석자 명단 기본 20행, 하단에서 추가/삭제)
2. [🔗 서명 링크 공유]의 QR을 참석자가 휴대폰으로 찍음 → `sign.html` 열림
3. 참석자가 성명·소속·사번 입력 후 서명 → 휴대폰 화면에 **서명 QR** 표시
4. 교육자 기기에서 [📷 서명 QR 스캔] → 휴대폰 화면을 카메라에 비추면 명단에 반영
5. 결재란(담당·팀장)의 [📱 QR] → 결재자가 휴대폰으로 서명 → 같은 방법으로 스캔하면 결재란에 반영
6. [📋 미서명자 → 미참석자] → [📄 PDF 저장]

## 파일
- `index.html` : 안전교육일지 양식 (교육자)
- `security.html` : 보안교육일지 양식 (참석자 명단 번호·사번·성명·확인, 좌우 2단)
- `form.js`, `style.css` : 두 양식이 함께 쓰는 화면 동작·스타일 (양식별 설정은 각 페이지의 `window.FORM`)
- `collect.js` : 서명 링크·QR 스캔 수합·명단 저장
- `sign.html` : 참석자/결재자 서명 → 서명 QR 생성 (`?s=세션&r=담당|팀장`)
- `sig.js` : 서명 획 압축/복원, QR 그리기
- `vendor/` : html2pdf, qrcode-generator, jsQR (외부 CDN 호출 없음, `qrcode.min.js`는 캐시된 예전 화면 호환용)

## 주의
- 이 저장소는 공개됩니다. 명단 등 개인정보를 파일에 넣지 마세요.
- 카메라 스캔은 https(GitHub Pages) 또는 localhost에서만 동작합니다.
- 서명 링크에는 세션 코드만 들어 있고, 새 링크를 발급한 뒤 이전 링크로 만든 서명 QR을 스캔하면 반영할지 묻습니다.
- 스크립트를 수정하면 `index.html`·`security.html`·`sign.html`의 `?v=` 번호를 올려 주세요.
