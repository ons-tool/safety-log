# 안전교육일지 (GitHub Pages 정적 버전)

서버·DB 없이 동작합니다. 입력 내용은 어떤 서버로도 전송되지 않습니다.

## 사용 순서
1. 교육자 PC에서 `index.html`을 열고 [👥 팀원 목록] 입력 → 저장 (이 PC 브라우저에만 저장)
2. [🔗 서명 링크 공유]의 QR을 참석자가 휴대폰으로 찍음 → `sign.html` 열림
3. 참석자가 성명·소속·사번 입력 후 서명 → 휴대폰 화면에 **서명 QR** 표시
4. 교육자 PC에서 [📷 서명 QR 스캔] → 휴대폰 화면을 카메라에 비추면 명단에 반영
5. [📋 미서명자 → 미참석자] → [📄 PDF 저장]

## 파일
- `index.html` : 교육일지 양식 (교육자)
- `collect.js` : 팀원 목록·서명 링크·QR 스캔 수합
- `sign.html` : 참석자 서명 → 서명 QR 생성
- `sig.js` : 서명 획 압축/복원
- `vendor/` : html2pdf, qrcodejs, jsQR (외부 CDN 호출 없음)

## 주의
- 이 저장소는 공개됩니다. 팀원 명단 등 개인정보를 파일에 넣지 마세요.
- 카메라 스캔은 https(GitHub Pages) 또는 localhost에서만 동작합니다.
- 서명 링크에는 세션 코드만 들어 있고, 새 링크를 발급하면 이전 서명 QR은 거부됩니다.
